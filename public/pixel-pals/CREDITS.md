# Pixel Pals art credits

Most art in this folder comes from [VS Code Pets](https://github.com/tonybaloney/vscode-pets) by Anthony Shaw. The
VS Code Pets project is released under the MIT License (`LICENSE-vscode-pets.txt`), but some of its art carries its
own license, noted below, which applies to those files instead: the dog sprites are CC BY-ND 4.0, and Finley has its
own MIT license. Only the "nano" backgrounds and the 8 fps sprites are copied. Credits as given by VS Code Pets:

- Dog: [NVPH Studio](https://nvph-studio.itch.io/dog-animation-4-different-dogs), licensed CC BY-ND 4.0 (`pets/dog/LICENSE.txt`). Akita: [Kevin Huang](https://github.com/kevin2huang).
- Fox: [Elthen](https://twitter.com/pixelthen).
- Clippy, Rocky, Zappy, rubber duck, snake, cockatiel, crab (Ferris) and Mod: [Marc Duiker](https://twitter.com/marcduiker). Ferris concept: [Karen Rustad Tölva](https://www.aldeka.net).
- Finley: Microsoft Corporation, MIT (`pets/finley/LICENSE.txt`).
- Turtle: enkeefe. Snail: [Kennet Shin](https://github.com/WoofWoof0). Panda: [Jessie Ferris](https://github.com/jeferris).
- Horse: adapted by [Chris Kent](https://github.com/thechriskent) from [Onfe](https://onfe.itch.io/horse-sprite-with-rider-asset-pack).
- Skeleton: adapted by [Chris Kent](https://github.com/thechriskent) from [MonoPixelArt](https://monopixelart.itch.io/).
- Other pets: VS Code Pets contributors.
- Winter theme: [Kiana Mosser](https://www.instagram.com/kianamosser/). Forest theme: [edermunizz](https://edermunizz.itch.io/free-pixel-art-forest). Castle theme: based on [GuttyKreum](https://guttykreum.itch.io/gothic-castle-game-assets). Other themes: VS Code Pets contributors.
- Speech bubble font: Silkscreen by Jason Kottke, SIL Open Font License 1.1.

Made for this project, under the project's own license: the deer sprites (`pets/deer/`), the pteranodon and
pterodactyl sprites (`pets/pteranodon/`, `pets/pterodactyl/`), the T. rex, triceratops, stegosaurus, brachiosaurus and
velociraptor sprites (`pets/t-rex/`, `pets/triceratops/`, `pets/stegosaurus/`, `pets/brachiosaurus/`, `pets/raptor/`),
the unicorn sprites (`pets/unicorn/`, `pets/alicorn/`, `pets/unicorn-foal/`, `pets/rainbow-unicorn/`,
`pets/starry-unicorn/`), the aurora colors (`aurora_*` files: recolors of the pets' own sprites, so the panda and Deno
ones are derived from VS Code Pets art and keep its license), the food (`foods/`), the Snowy peak theme
(`backgrounds/peak/`), the Autumn lake theme with its stepping stones (`backgrounds/lake/`), the Jurassic jungle and
Volcano valley themes (`backgrounds/jungle/`, `backgrounds/volcano/`, generic prehistoric scenery, nothing from a film),
the Classroom and Science class themes (`backgrounds/classroom/`, `backgrounds/science/`), and the Sunset farmhouse,
Sunset ranch, Overgrown city, Misty cove, Karst peaks, Portal gate and Castle gate themes (`backgrounds/farmhouse/`,
`backgrounds/ranch/`, `backgrounds/city/`, `backgrounds/cove/`, `backgrounds/karst/`, `backgrounds/portal/`,
`backgrounds/gate/`: original pixel art painted from mood pictures, generic shapes, no logos, emblems or characters
from any game). The Big panda and Little panda reuse the panda sprites at another size.

Left out on purpose: the cat (its artist asked that it is not redistributed) and Totoro (a Studio Ghibli character).
